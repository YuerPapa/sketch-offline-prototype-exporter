# Sketch Offline Prototype Exporter

将 Sketch 画框和已有原型连线导出为一个可离线打开的 HTML 文件。接收者使用电脑浏览器即可演示，无需 Sketch 或第三方账号。

当前版本：**1.2.0**。已在 **Sketch 2026.1.2（228390）** 验证。

## 安装

1. 下载仓库中的 [插件安装包](Offline%20Prototype%20Exporter.sketchplugin.zip?raw=1)。
2. 解压 ZIP，双击 `Offline Prototype Exporter.sketchplugin`。
3. 在 Sketch 中打开设计稿，进入需要导出的页面。

## 使用

在 Sketch 菜单中选择 **插件 → 离线原型导出**：

| 命令 | 导出范围 |
| --- | --- |
| 导出当前页为 HTML… | 当前页面全部可见画框，并补充连线关联的其他页面画框。 |
| 导出所选流程为 HTML… | 从选中的画框或图层所属画框开始，导出沿现有连线可到达的画框。 |

选择保存位置后，会自动打开生成的 HTML。把 HTML 文件发送给他人即可；图片和播放器都已内嵌。

## 演示界面

- 左侧页面列表默认展开，固定占据布局空间；右侧预览自动适应剩余区域。
- 目录可收起，收起后左上角保留红底图标入口。
- 支持返回、前进、回到起始页、当前画面高亮和热点提示。
- 支持铺满窗口、适应宽度、完整画面、实际尺寸和全屏。
- 铺满窗口时，在存在足够留白的画面中延展留白，保持文字、图标比例及底部按钮的点击位置。

| 快捷键 | 操作 |
| --- | --- |
| B | 收起或展开页面列表 |
| H | 切换热点提示 |
| R | 回到起始页 |
| F | 切换全屏 |
| Alt + ← / → | 返回或前进 |

## 支持范围与限制

画框以图片保留外观，原型连线转换为点击区域。支持嵌套图层连线、跨页关联、返回动作，以及隐藏、裁剪和基本遮挡处理。

输入、真实查询、文件上传等操作展示的是设计稿中的预设画面，不会转换成业务程序。没有连线的按钮不会自动产生行为。

跳转直接切换画面；高级动画、滚动固定层、复杂非矩形蒙版及组件内部连线尚未完整重建。直接设置在组件实例上的连线可以导出；检测到内部连线时会提示。

旋转图层的点击区域采用变换后的外接矩形。缺少可延展留白的画面按宽度完整展示，超高内容可滚动。

## 开发

项目使用 Node.js 自带模块，无需安装运行依赖。

```sh
npm run build
npm test
```

- `src/core.js`：几何计算、连线遍历和 HTML 数据序列化。
- `src/exporter.js`：Sketch 文档读取、画面导出、保存及菜单命令。
- `Offline Prototype Exporter.sketchplugin/Contents/Resources/player.html`：独立 HTML 播放器模板。
- `build.js`：将源码合并为插件中的 `export.js`。

修改源码后运行 `npm run build`，再重新安装插件包或同步到本机插件目录。测试使用合成数据，不包含真实设计文档或导出业务演示。
